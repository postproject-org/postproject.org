Keep your media connected across applications.

Integrations and demos

Try these experimental integrations with a test project. Select the same local .pproj file in each application to share media knowledge. Your edits, compositions and tracks stay in their familiar projects; copy media separately when needed.

  • Blender — reconnect moved movies, sounds and image sequences in the Sequencer, and keep track of the inputs behind your renders.
  • Kdenlive — find renamed or moved clips when reopening an edit, and check whether proxies still match their source footage.
  • OBS — keep completed recordings and their details available to other participating applications.
  • Natron — reconnect moved image sequences to existing Reader nodes and keep your composition intact.
  • Ardour — find renamed or moved audio files by their file contents and reconnect them to an existing session.
  • OpenAssetIO Manager and OTIO demo — find timeline media without depending on its original file paths, using OpenAssetIO to connect the application to PostProject.
  • Nuke 17.0v1 — a prepared trial for finding moved plates without rebuilding Reader nodes; it has not yet been run in licensed Nuke.

These pilots currently require building an extension or a matching application. Each linked guide explains setup, supported versions, tested behavior and removal. They are early integrations for evaluation, rather than ready-made production installations.

The walkthroughs show two tested handoffs: OBS to Blender, and Kdenlive through Blender to the OpenAssetIO Manager. They share media knowledge; they do not translate timelines or automatically transfer your files.

For software developers

Give your application a shared memory for media.

Add moved-media recovery and render history without building a separate tracking system for every application. C, C++, Python and command-line interfaces let your software share one local production file and learn what other applications changed. The OpenTimelineIO demo shows how OpenAssetIO finds timeline media through PostProject. Your application stays in control when files are missing or several candidates match.
