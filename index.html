Open-source media sharing for film and video software

Keep your media connected across applications.

Spend less time reconnecting moved clips and tracing the footage behind a render. PostProject lets participating applications share that knowledge, while you keep using their familiar projects and storing your media where you choose.

Good to know

Early pilots, worth the setup

For now you build an extension or a matching application version yourself. Each guide walks you through setup, supported versions and how to remove it again. Start with a test project.

PostProject shares what applications know about your media. It does not convert timelines or copy your files.

For software developers

Give your application a shared memory for media.

Add moved-media recovery and render history without building a separate tracking system for every application. C, C++, Python and command-line interfaces let your software share one local production file and learn what other applications changed. The OpenTimelineIO demo shows how OpenAssetIO finds timeline media through PostProject. Your application stays in control when files are missing or several candidates match.
