Open-source media sharing for film and video software

Keep your media connected across applications.

PostProject lets participating applications share what they know about your media: its identity, where to find it, and which inputs produced a result. Your applications keep their own native projects, and your media files stay where you store them. Start with a pilot integration and an explicitly selected local production.

Integrations and demos

These are experimental integrations. Select the same local .pproj production in each participating application. Timelines, node graphs and tracks stay in their native projects; media transfer is separate.

  • Blender — build the extension for identity adoption, relinking and render provenance.
  • Kdenlive — build the optional pilot for clip recording, missing-media recovery and proxies.
  • OBS — build the pilot to register finalized recordings.
  • Natron — build the Reader pilot for compact sequences and explicit relinking.
  • Ardour — build the audio pilot to recover renamed sources by content.
  • OpenAssetIO Manager and OTIO demo — build matching packages and resolve media references through a standard host interface.
  • Nuke 17.0v1 — prepared trial; licensed execution pending.

Recorded automated Linux checks cover Blender 5.2.2, Kdenlive 26.08.1, OBS 32.2.2, Natron 2.5.0 and Ardour 9.8. Follow each installation guide for the matching SDK, tested scope and removal or plugin-free fallback. Current development sources require a source build or matching review artifacts.

Knowledge accumulates as apps participate: OBS records identity, Blender can reuse it and add render provenance, and a configured consumer can resolve the recorded result. The two walkthroughs demonstrate separate handoffs; a combined three-app recording workflow has not been qualified.

For software developers

Use media identities across application boundaries.

A production is a single database file that several programs can use together. Every change is recorded, so each program can ask what the others have changed since it last looked. PostProject also works with open industry standards: the OpenTimelineIO demo refers to media by PostProject identity, and a configured OpenAssetIO Manager resolves those references on this computer. Missing or ambiguous files remain explicit results. Developers can use PostProject from C, C++, Python or the command line. This workflow uses local production data.
